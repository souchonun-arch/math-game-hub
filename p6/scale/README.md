# 認識比例尺｜像素製圖師的縮尺密碼

澳門小六數學第 13 課「認識比例尺」互動教材，單檔離線 HTML，無需安裝。

- 線上網址：`https://souchonun-arch.github.io/math-game-hub/p6/scale/`
- 對應教材：教育出版社《數學》第六冊第 13 課，基本學力 `B-2-15`
- 學習範圍：比例尺的意義、統一單位求比例尺、線段比例尺、`10 : 1` 放大比例尺
- 不包含：第 14 課「比例尺的應用」、已知比例尺反求長度、正比例、反比例等後續概念

## 與《解比例》並存

本教材放在 `p6/scale/` 獨立子目錄，不修改總站首頁，也不會覆蓋原先已發佈的《解比例》互動教材。兩份教材各有獨立網址，可同時保留給全班使用。

## 學生流程

1. 先完成 8 題加權分層診斷（滿分 15 分）。
2. 系統按層級派發 8 題練習：分步列式 4 題、錯例醫院 2 題、出門票 2 題。
3. 每題一次作答即鎖定；答錯後自動顯示提示並記入錯題本，須以變式題重練訂正。
4. 在「我的學習報告」填寫姓名班別，下載 PNG 報告卡後上傳給老師。

時間預算約 20 分鐘；拓展層較深，實際約 20 至 22 分鐘。

## 資料與私隱

所有作答紀錄只存放在學生瀏覽器的 `localStorage`（鍵名 `bz_scale_pixel_v1`），不會上傳伺服器。共用裝置會共用進度；報告卡由學生自行下載後提交。

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 教材主檔，單檔自足，可雙擊離線開啟 |
| `qrcode.min.js` | 老師專用報告 QR 功能 |
| `.nojekyll` | 讓 GitHub Pages 直接提供靜態檔案 |
| `source/build.py` | 冪等生成器，內建書面語、章節邊界、題庫品質檢查 |
| `source/upgrade-v3*.py` | v3 題數與分層升級腳本 |
| `source/smoke.js` | jsdom 自動化測試（243 項） |
| `source/pages-check.js` | 本機 HTTP 上線模擬檢查（23 項） |
| `source/shot.js` | 實機瀏覽器截圖與報告卡 PNG 驗證 |

更新教材時，重新執行 `source/build.py` 後，把產出的 HTML 覆蓋到本目錄的 `index.html` 再推送即可。
