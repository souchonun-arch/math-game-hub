## 一、教材內容與邊界

本課嚴格對應進度表所列的第 13 課四個教學目標：

1. 認識比例尺的意義：`比例尺 ＝ 圖上距離 : 實際距離`。
2. 學習根據地圖上的距離和實際距離，計算比例尺。
3. 認識線段比例尺，並換算成數值比例尺。
4. 數學小百科：認識放大比例尺 `10 : 1` 的意思。

題庫出自：課本 p.52 第 13 課第 2 題附加例題（`1 : 480`、`1 : 2000`、`1 : 160`、`1 : 750`）、《澳門新思維數學習作》練習 13、自編補充工作紙冊第 13 課（`950 km／19 cm`、`363 m／1.1 cm`）、工作紙 `24.png`。每一題皆標示教材原文依據與預估秒數，老師可於「老師專用 → 教材依據一覽」逐題核對。

> 本教材**不包含**後續章節（第 14 課「比例尺的應用」）的反求長度、依比例尺作圖，亦不包含正比例、反比例、體積等未教概念。生成腳本內建章節邊界檢查，混入時會拒絕輸出。

## 二、學生使用流程

1. 開啟老師提供的網址，進入「像素製圖屋」。
2. 先完成 **5 題分層診斷**（比的化簡、單位換算、前項化為 1）。題目依難度配分：★ 題 1 分、★★ 題 2 分、★★★ 題 3 分，**滿分 9 分**；系統以加權得分加上基礎題門檻判定層級，同一層級內仍可從得分看出程度差異。**每題只作答一次，答錯不補答，診斷完成後不可重做**。未完成診斷前，練習不會開啟。
3. 系統依診斷結果配對 **★ 基礎層／★★ 發展層／★★★ 拓展層**，每層只派 **4 題出門票**，四題皆為本層難度且屬同一概念主題鏈。分步列式與錯例醫院改為「參考示範」，列出本層題目、答案、解釋與教材依據，**不必作答**。
4. 出門票每題**只作答一次**，送出後即鎖定，不能修改。答錯時系統自動記入錯題本，並自動顯示提示；作答前不能查看提示。答案欄只須填寫數字，系統會忽略空白與逗號。
5. 錯題可透過「錯題重練」作答同類型變式題（更換數字、不更換方法），答對後標記為「已訂正」。
6. 開啟「📊 我的學習報告」，填入姓名與班別，按「🖼 產生報告圖片」，再按「💾 下載 PNG」。
7. 將該 PNG 圖片上傳至老師指定的網站或平台，即完成繳交。

> 報告圖片已包含姓名、層級、答題統計、錯題與錯因、學習建議及本層配對紀錄。

## 六、更新教材

1. 於本機修改 `source/build.py` 頂部的資料區（`CFG`／`DIAG`／`DATA`／`BADGES`／`PLAN`）。
2. 重新執行 `python3 build.py`，產出新的 `認識比例尺-像素風.html`。
3. 把新檔覆蓋為本資料夾的 `index.html`，再推送至 GitHub。
4. GitHub Pages 會自動更新，學生重新整理頁面即可看到新版。

> 生成腳本內建品質檢查：學生可見文字不得出現粵語口語字、不得混入後續章節概念、每題必須附教材依據與預估秒數、答案必須為純數字、不得出現「第 N 組」這類無意義前綴，角色與作答用語須一致，並檢查診斷加權分層（滿分 9 分）、不可重做與每層 4 題出門票配對，以及分層與作答機制的完整結構檢查。另會**真正核算各層出門票逐題秒數**，核對教材上印出的 5–9 分鐘／全程 13–17 分鐘區間，並檢查未超出單科 20 分鐘上限；若改題庫後數字對不上，腳本會拒絕輸出。
