安全性說明（請睇一次）

• 密碼閘只係防學生誤觸，唔係真正嘅安全機制。
• 真正嘅鑰匙係 token。冇 token 嘅人撳上傳只會得到 401，改唔到任何嘢。
• 唔好喺學校公用電腦勾「記住我」或者長期開住呢頁。
• Token 建議設 90 日有效期，只需要 Contents: Read and write 權限，只勾呢一個 repo。
• 想改密碼：打開 assets/js/admin.js 搜 PASSWORD，改個字串再上傳。
